# 0010 — Unsigned .dmg on GitHub Releases, our own updater
**Context.** No App Store, no Apple developer account. Squirrel.Mac (Electron autoUpdater/electron-updater) requires a signed app.
**Decision.** electron-builder builds an ad-hoc-signed arm64 `.dmg` on a macOS runner and attaches it to a GitHub Release (repo is public: free minutes, no token). The app checks `releases/latest` on launch and daily; if newer, a notification offers "Download & install", which downloads the dmg, opens it and quits so Matthew drags the new version over.
**Consequences.** First launch needs right-click → Open. Updates are two clicks rather than silent.

## Addendum (JD-74, 2026-10-20): the app replaces itself
**Context.** Matthew wants updates without downloading by hand, still without a developer account (option A).
**Decision.** Every release also carries a `.zip` of `JARVIS Desk.app` and `latest-mac.json` (version, zip URL, size, sha256). When a newer `desk-v*` release has one and the app runs from a folder it can write to, the zip downloads in the background to `userData/updates/<version>/`, is checked (sha256 against the manifest, the URL on this repo's release over https, `ditto -x -k`, the Info.plist version, `codesign --verify`) and offered as Restart now / Later. A detached shell helper (`desk/main/updateInstaller.ts`) waits for the app to quit, moves it to `updates/previous.app`, moves the new one in, clears quarantine and relaunches; it puts the previous app back if a move fails or the new version doesn't report "started" within 60 s. Settings → Install updates automatically (on by default) also installs a downloaded update on quit, without relaunching. Anything else (the disk image, a read-only folder, a failed download or check, a version that rolled back once) falls back to the `.dmg` flow above, with the reason in the notice and `desk.log`.
**Consequences.** Updates are one click, or none. An ad-hoc signature doesn't prove who built the app, so the trust is the repo's releases over https plus the manifest's sha256 (from the same release). The first release with the zip installs the old way; the one after it is the first to install itself.
